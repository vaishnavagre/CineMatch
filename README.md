# CineMatch
CineMatch is a content-based movie recommendation system that recommends similar movies based on their characteristics. It provides the Top 5 movie recommendations through a simple and user-friendly Streamlit web interface.

Features
Select a movie from the available movie list
Get Top 5 similar movie recommendations
Simple and interactive Streamlit interface
Displays recommendation match percentage
Dataset

The project uses the following datasets:

TMDB 5000 Movies Dataset — tmdb_5000_movies.csv
TMDB 5000 Credits Dataset — tmdb_5000_credits.csv

The original CSV datasets are not included in this repository.

Technologies Used
Python
Pandas
Scikit-learn
Streamlit
Pickle

Conclusion

CineMatch provides a simple way to discover movies similar to a user's selected movie through an interactive web application.
